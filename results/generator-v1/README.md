# Results from generator version 1 (superseded)

`EVELYN68961.csv` holds 24 fits from the first step 2 run, which was stopped
on 2026-10-07 when two faults were found in the simulated patients (see
`docs/calibration.md`). The code that produced them is at the git tag
`generator-v1`.

These rows are kept as a record. They are not used in any report and must not
be pooled with results from another generator version. The file predates the
columns `generator_version`, `host` and `code_commit`.
